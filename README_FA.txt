Borsa Pattern v0.8

تغییرات اصلی:
- تلاش برای ترمیم نام واقعی نمادها با MetadataWorker و داده‌ی روز بازار.
- تاریخ‌های قابل نمایش شمسی/جلالی و اعداد فارسی.
- انتخاب بازارهای مورد بررسی: بورس، فرابورس، پایه زرد، نارنجی، قرمز و سایر.
- فیلتر انتخابی روی دانلود افزایشی، تحلیل تاریخی و فرصت‌های زنده اعمال می‌شود.
- تحلیل سریع: هر مرحله 240 کاندید با حداکثر 4 درخواست همزمان.
- رابط کاربری جدید با داشبورد، کارت‌های آماری، کارت سیگنال و تاریخچه خواناتر.
- دیتابیس از نسخه 1 به 2 با Migration واقعی ارتقا می‌یابد و داده‌های قبلی در صورت Update معتبر حفظ می‌شوند.
- versionCode=8 و versionName=0.8

نکته مهم درباره Update:
APKهای Debug که روی runnerهای مختلف GitHub ساخته می‌شوند ممکن است امضای متفاوت داشته باشند.
برای Update پایدار باید یک Release Signing Key ثابت در GitHub Secrets تنظیم شود.
اولین مهاجرت از APK قدیمی با امضای Debug به Release ثابت ممکن است نیاز به حذف یک‌باره نسخه قدیمی داشته باشد؛ بعد از آن نسخه‌های بعدی باید با همان کلید ساخته شوند.
