Borsa Pattern v1.1

تغییرات این نسخه:

1) دسته‌بندی نوع اوراق مطابق نمای درخواستی:
- سهام
- فرابورس - بازار پایه
- تسهیلات مسکن
- حق تقدم
- اوراق بدهی
- اختیار معامله
- آتی
- صندوق سرمایه گذاری
- بورس کالا
- معاملات پایانی TAL
- انرژی

برای «فرابورس - بازار پایه» انتخاب جزئی زرد، نارنجی و قرمز نیز حفظ شده است.
انتخاب‌ها روی دریافت تاریخچه، تحلیل الگو، فرصت‌های زنده و Paper Trading اعمال می‌شوند.

2) رفع گیر کردن تحلیل روی 0/240:
- دیگر 240 coroutine به صورت همزمان روی semaphore بلوکه نمی‌شوند.
- تحلیل در دسته‌های کوچک 4تایی اجرا می‌شود.
- batch پیش‌فرض 120 مورد است.
- timeout واقعی OkHttp اضافه شده: callTimeout=15s و readTimeout=12s.
- هر مورد ناموفق ERROR می‌شود تا تحلیل برای همیشه روی یک کاندید گیر نکند.

3) دیتابیس:
- schema از 4 به 5 ارتقا یافته است.
- فیلد instrumentType به symbols اضافه شده.
- CategoryRepairWorker نمادهای موجود را بعد از آپدیت بدون دانلود دوباره تاریخچه دسته‌بندی می‌کند.

4) آپدیت پایدار APK:
- Workflow دیگر APK Debug تولید نمی‌کند.
- فقط Release APK با Signing ثابت ساخته می‌شود.
- برای Build باید چهار GitHub Secret زیر از قبل تنظیم شده باشند:
  BORSAPATTERN_KEYSTORE_BASE64
  BORSAPATTERN_KEYSTORE_PASSWORD
  BORSAPATTERN_KEY_ALIAS
  BORSAPATTERN_KEY_PASSWORD
- اگر Secrets تنظیم نشده باشند، Build عمداً متوقف می‌شود تا اشتباهی APK با امضای متفاوت نصب نشود.

نکته درباره اولین نصب Release:
اگر نسخه فعلی گوشی با Debug Key دیگری امضا شده باشد، Android اجازه Update به Release Key جدید را نمی‌دهد.
ممکن است فقط برای ورود به زنجیره Release ثابت یک بار حذف و نصب لازم باشد.
از آن نسخه Release به بعد، تمام نسخه‌ها باید با همین Secrets ساخته شوند تا Update مستقیم و حفظ دیتای برنامه ممکن باشد.

versionCode=11
versionName=1.1
