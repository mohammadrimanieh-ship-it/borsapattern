Borsa Pattern v0.9

تغییرات اصلی:
- ترمیم نام نماد به‌صورت مرحله‌ای با Instrument/GetInstrumentInfo برای نمادهای ناشناخته.
- در حین MarketWatch اگر نام نماد پیدا شود، جدول symbols همان لحظه اصلاح می‌شود.
- تحلیل تکنیکال همزمان: RSI14، MACD، MA20، MA50 و شکست سقف 20روزه.
- امتیاز نهایی 0 تا 100:
  45% الگوی صف
  30% تکنیکال
  25% حجم
- کارت فرصت‌ها امتیاز کل، الگو، تکنیکال، حجم و RSI را جدا نمایش می‌دهد.
- وضعیت دریافت تاریخچه، تحلیل الگو و تکمیل نام نمادها سه بخش جدا دارند.
- تاریخ‌های رابط کاربری شمسی باقی مانده‌اند.
- انتخاب بازارها حفظ شده است.
- دیتابیس با Migration 2->3 ارتقا می‌یابد و در Update معتبر اطلاعات قبلی حفظ می‌شوند.

این امتیازها ابزار تحقیق و بک‌تست هستند و تضمین سود یا توصیه قطعی خرید/فروش نیستند.
