Borsa Pattern Android v0.2

این نسخه:
- تاریخچه یک‌سال را مرحله‌ای می‌گیرد
- در Room ذخیره می‌کند
- روزهای کاندید حرکت تا سقف را علامت‌گذاری می‌کند
- صفحه فرصت‌های فعلی دارد
- اسکن زنده دستی دارد
- WorkManager برای رصد پس‌زمینه دارد
- اعلان امتیازهای بالا دارد

مهم:
امتیاز فعلی نسخه آزمایشی است. هنوز BestLimits زنده + بازسازی کامل تاریخی + مدل «صف شد / صف نشد»
در خود APK نهایی نشده‌اند. بنابراین این نسخه را برای معامله واقعی مبنا قرار ندهید.

برای ساخت APK:
پروژه را با Android Studio باز کنید، Sync Gradle را انجام دهید و Build > Build APK(s) را بزنید.
